React + Python Backend Integration
========================================

CHANGES MADE:
1. Updated src/App.tsx to use API service
2. Added backend health check on load
3. Automatic fallback to mock data if backend unavailable
4. Backend status indicator in UI (green = connected, yellow = offline)

HOW TO RUN:
-----------

Step 1: Start Python Backend
  Double-click: RUN_BOTH.bat
  OR manually:
    venv\Scripts\activate
    python -m api.main

Step 2: Start React Frontend
  npm run dev

Step 3: Open Browser
  http://localhost:3000

FEATURES:
---------
✅ Auto-detects backend availability
✅ Uses Python backend for stock scanning
✅ Fetches portfolio data from database
✅ Falls back to mock data if backend offline
✅ Shows connection status in UI

API ENDPOINTS USED:
-------------------
- GET  /api/health - Check backend status
- GET  /api/suggestions - Fetch portfolio
- POST /api/scan - Run stock scan
- GET  /api/portfolio/performance - Get live metrics

TESTING:
--------
1. Start backend + frontend
2. Look for green dot "Backend Connected" in UI
3. Run a stock scan - should use Python backend
4. Stop backend - UI switches to "Offline Mode"
5. Scan still works with mock data
