========================================
HOW TO RUN - NSE Alpha Quant
========================================

OPTION 1: Streamlit Only (Easiest) ✅
--------------------------------------
Double-click: RUN_STREAMLIT.bat
OR run: streamlit run app.py

Access: http://localhost:8502
Features: Everything in one app


OPTION 2: React + Python Backend
--------------------------------------
Double-click: RUN_BOTH.bat

This will start:
1. FastAPI Backend (Port 8000)
2. React Frontend (Port 3000)

Access:
- React UI: http://localhost:3000
- API: http://localhost:8000
- API Docs: http://localhost:8000/api/docs

Note: React needs to be updated to connect to backend
(Currently uses mock data)


OPTION 3: Manual Start
--------------------------------------
Terminal 1 - Backend:
  venv\Scripts\activate
  python -m api.main

Terminal 2 - Frontend:
  npm run dev


========================================
RECOMMENDED: Use Streamlit (Option 1)
========================================
It's already integrated and working!
